# Desafio M04 - POO Java

Projeto com as 4 tarefas do desafio.

## Como abrir no IntelliJ IDEA
1. Extraia o arquivo ZIP.
2. Abra a pasta `Desafio_M04_POO` no IntelliJ IDEA.
3. O código-fonte está em `src`.
4. Execute o `main` da tarefa desejada:
   - `task1.SistemaFuncionarios`
   - `task2.SistemaUniversidade`
   - `task3.FolhaDePagamento`
   - `task4.SistemaRelatorios`

Não é necessário banco de dados ou biblioteca externa.
